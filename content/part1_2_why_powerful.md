# 1.2 為什麼 LLM 這麼強

## 不是因為它聰明，是因為它見多識廣

一個 LLM 在訓練過程中讀過的資料量，遠超任何人一輩子能接觸到的。書、論文、程式碼、法律文件、客服對話、維基百科、論壇討論，全部壓進模型的參數裡。

這代表什麼？它見過幾乎所有你能想到的 pattern。

當你請它寫一封商務英文信，它不是在「創作」，它是在從見過的幾百萬封商務信中，組合出一個統計上最合理的版本。當你請它 debug 一段 Python，它是在從見過的幾十億行程式碼中，找到最接近的修正 pattern。

## 強在哪裡

### 1. Pattern 存在的地方，它都能幫

只要一件事在人類留下的文字中有足夠多的範例，LLM 就能做得不錯：

- 翻譯：因為平行語料庫數量龐大
- 摘要：因為「長文 → 重點」的 pattern 到處都有
- 程式碼生成：因為 GitHub 上有幾十億行 open source code
- 格式轉換：因為 JSON、CSV、XML 之間的轉換在訓練資料中大量出現

### 2. 「夠好」的任務，它速度碾壓

很多工作不需要完美，需要的是速度跟覆蓋率。LLM 在這類任務上超有優勢：

- 生成初稿讓人類修改，比人類從零開始快 5-10 倍
- 分類一千封 email 的意圖，不需要 100% 正確，90% 就夠用
- 把會議逐字稿整理成結構化筆記，不完美但省下 80% 的時間

### 3. 跨領域的通用性

傳統 AI 是一個模型做一件事。要做情感分析就訓練一個情感分析模型，要做 NER 就訓練一個 NER 模型。

LLM 是一個模型做一百件事。同一個 Claude 或 GPT，可以翻譯、寫 code、分析法律條文、生成測試資料、整理會議記錄。你不需要為每個任務重新訓練，只需要給不同的 prompt。

這是一個 paradigm shift：從 task-specific model 變成 general-purpose platform。

### 但它不是萬能的：Car Wash Test

有一個很好的例子可以說明 LLM 的「強」到底是什麼性質的強。

> 問題：「我想洗車。洗車場在 50 公尺外。我應該走路還是開車去？」

在 53 個主流模型的測試中，只有 11 個第一次就答對。其他 42 個都回答「50 公尺很近，走路比較環保、省油」。

它們完全忽略了一個最基本的事實：你要洗的是車，車本身要到洗車場啊。

這不是因為模型「笨」。它是因為訓練資料中「短距離 → 走路」這個 pattern 太強了。模型在做 pattern matching，不是在做 contextual reasoning。當正確答案需要跳脫常見 pattern 時，LLM 就容易出錯。

更值得注意的是一致性測試：讓每個模型回答同一個問題 10 次，只有 5 個模型能 10 次都答對。很多模型有時對、有時錯，表現不穩定。

相比之下，10,000 個人類測試者中有 71.5% 答對，表現超過 53 個模型中的 46 個。

這告訴我們：LLM 的強是建立在 pattern 的強上。當問題需要的不是 pattern 而是 reasoning 時，它就容易出包。理解這一點，你才知道什麼時候該信任它、什麼時候該多想一步。

> 參考：[The Car Wash Test](https://opper.ai/blog/car-wash-test)（2026 年初的測試結果，模型排名會隨時間變動）

## 為什麼「現在」特別強

這不是一夜之間發生的。三個因素同時成熟：

| 因素 | 發生了什麼 |
|------|-----------|
| 資料規模 | 網路累積了幾十年的文字內容，提供前所未有的訓練資料量 |
| 算力突破 | GPU 集群讓訓練幾千億參數的模型變得可行 |
| 架構創新 | 2017 年的 [Transformer 架構](https://arxiv.org/abs/1706.03762)讓 Attention 機制可以大規模平行運算 |

這三個條件缺一不可。十年前有資料但沒算力，有算力但沒 Transformer。現在三者同時到位，所以 LLM 的能力在短短幾年內爆發。

重點是：這三個因素都還在加速。模型會繼續變大、變快、變便宜。今天做不到的事，不代表明年也做不到。

## 網路資料都用完了，為什麼新模型還能更強？

一個合理的問題：如果現有模型已經把整個網路的資料都讀過了，下一代模型要靠什麼變得更強？

答案是：更多的資料不是唯一的進步方向。

### 1. 推理訓練 (Reasoning Training)

早期的 LLM 只學會了「預測下一個字」。新一代模型（如 o3、Claude Opus）在訓練過程中額外加入了推理能力的強化。

具體做法是在推理時讓模型花更多時間「思考」（thinking tokens），而不是直接輸出第一個想到的答案。就像考試時，從「憑直覺秒答」進化成「先在草稿紙上推演再作答」。花的時間多了，但準確度大幅提升。

### 2. 合成資料 (Synthetic Data)

用現有的強模型去生成高品質的訓練資料，再用這些資料訓練下一代模型。聽起來像「自己教自己」，但重點是你可以精確控制合成資料的品質和分布，補上真實資料不夠的地方。

例如：真實世界的數學證明資料很少，但你可以讓強模型生成幾百萬道數學題和解題過程，用來訓練下一代模型的數學推理能力。

### 3. 架構改進

Transformer 不是終點。研究者一直在改進模型架構：更高效的 attention 機制、更好的記憶結構、更低的推理成本。同樣的資料量，用更好的架構就能學到更多東西。

### 4. 更好的訓練方法

RLHF（Reinforcement Learning from Human Feedback）讓模型學會了「人類覺得什麼是好的回答」。新的訓練方法持續在改善模型對指令的遵循能力、安全性、和一致性。

所以進步的來源不只是「餵更多資料」，而是多管齊下：

| 進步方向 | 效果 |
|---------|------|
| 推理訓練 | 同一個模型，花更多時間思考，得到更好的答案 |
| 合成資料 | 填補真實資料的空白，強化特定能力 |
| 架構改進 | 同樣的資料，學到更多、推理更快 |
| 訓練方法 | 更好地對齊人類的期望和偏好 |

## Quiz

**Q1.** Car Wash Test 裡，大部分模型回答「走路去洗車場」。為什麼它們會答錯？

- A) 模型沒有被訓練過洗車相關的資料
- B) 「短距離 → 走路」這個 pattern 太強，蓋過了情境推理
- C) 模型的 context window 不夠大
- D) 問題的中文太難理解

<details><summary>答案</summary>B。訓練資料中「50 公尺 → 走路」的 pattern 出現頻率遠高於「洗車需要把車開過去」的推理。LLM 是在做 pattern matching，當正確答案需要跳脫常見 pattern 時就容易出包。</details>

**Q2.** 網路資料都用得差不多了，新模型還能更強，主要靠什麼？（複選）

- A) 推理訓練：讓模型花更多時間思考
- B) 找到更多還沒被爬過的網站
- C) 合成資料：用強模型生成訓練資料
- D) 架構改進：同樣的資料學到更多

<details><summary>答案</summary>A、C、D。進步的方向已經從「餵更多資料」轉向推理訓練、合成資料、架構改進和訓練方法的多管齊下。</details>

**Q3.** LLM 幫你寫的商務英文信品質很好，這代表？

- A) LLM 理解商務禮儀
- B) 訓練資料中有大量類似的信件，它組合出統計上最合理的版本
- C) LLM 有商務溝通的專業知識
- D) LLM 在即時查詢商務信範本

<details><summary>答案</summary>B。LLM 的能力建立在 pattern 上。訓練資料中商務信的範例夠多，所以它組合出來的結果品質不錯。</details>
