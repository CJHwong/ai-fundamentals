# 1.1 核心機制：LLM 是怎麼「想」的

## 一句話版本

LLM 做的事情只有一件：根據前面所有的文字，預測下一個最可能出現的字。

## 從預測到理解的錯覺

當你問 ChatGPT「台灣的首都是什麼」，它不是去查資料庫，也不是「知道」答案。它做的事情是：在它讀過的海量文本中，「台灣的首都是」後面最常接的字是「台」「北」。

這就是 next-token prediction。

聽起來很蠢對吧？就是在猜下一個字而已。但當你把這個機制放大到幾千億個參數、用整個網路的資料去訓練，一件很神奇的事發生了：這個「猜字遊戲」開始展現出推理、翻譯、寫程式、甚至創作的能力。

這些能力不是被寫進去的，是從大量的 pattern 中**湧現 (emerge)** 出來的。而且 LLM 在訓練時其實只讀過這些資料一次（一個 epoch），不像人類需要反覆複習。讀一次就能學到這麼多，靠的是模型的規模和架構。

## Attention：不是每個字都一樣重要

LLM 在預測下一個字的時候，會回頭看前面所有的文字，但它不是平均地看。它會動態分配權重，決定「哪些字對我現在這個預測比較重要」。這個機制叫做 **Attention**。

### 試試看

閉上眼睛，聽我唸四句話，每句話之後想一下「你接下來最想做什麼」：

1. 「今天天氣很好，適合出去走走。」
2. 「今天天氣很好，適合出去走走。但是我的腳受傷了。」
3. 「今天天氣很好，適合出去走走。但是我的腳受傷了。但是我有一個必須現場參加的會議。」
4. 「今天天氣很好，適合出去走走。但是我的腳受傷了。但是我有一個必須現場參加的會議。我手邊有一支拐杖。」

同樣是「今天天氣很好」這幾個字，它的重要性在四句話之間一直在變。第一句的時候很重要，後來越來越不重要。每進來一個新資訊，權重就會重新分配。

這就是 Attention。LLM 每預測一個字的時候，都在做一模一樣的事。

## 關鍵概念

| 概念 | 白話解釋 |
|------|---------|
| Token | LLM 處理文字的最小單位，可以是一個字、一個詞、或詞的一部分 |
| Next-token prediction | LLM 的核心運作：根據前文預測下一個最可能的 token |
| Attention | 動態分配權重的機制，決定前文中哪些 token 對當前預測最重要 |
| Emergence | 大規模訓練後自然冒出來的能力，不是被刻意寫進去的 |

## Quiz

**Q1.** LLM 回答「台灣的首都是台北」，是因為？

- A) 它查了資料庫
- B) 它理解了地理知識
- C) 「台灣的首都是」後面最常接的字就是「台北」
- D) 工程師把這個答案寫進程式裡

<details><summary>答案</summary>C。LLM 做的是 next-token prediction，根據訓練資料中的統計 pattern 預測下一個字。</details>

**Q2.** 在 Attention 練習中，「今天天氣很好」這幾個字的重要性隨著新資訊加入而改變。這說明了什麼？

- A) LLM 只看最後一句話
- B) LLM 對所有文字給予相同的關注度
- C) LLM 會動態調整每個 token 的權重
- D) LLM 會忽略前面的句子

<details><summary>答案</summary>C。Attention 機制會根據當前的預測需求，動態重新分配前文中每個 token 的權重。</details>
