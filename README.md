# AI Fundamentals

給所有角色的 AI 入門指南，涵蓋 LLM 的運作原理、Agent 架構、以及實務上怎麼跟 AI 協作。

## 內容

1. **LLM 怎麼想的** - 核心機制、為什麼強、天花板在哪
2. **Agent** - 什麼是 Agent、怎麼補上 LLM 的限制、目前能做到什麼
3. **實務應用** - Context Engineering、平行化、企業應用、各角色的實務建議

含互動式測驗（各章節小測驗 + 24 題綜合測驗）。

## 閱讀

👉 **[https://cjhwong.github.io/ai-fundamentals/](https://cjhwong.github.io/ai-fundamentals/)**

## 開發

編輯 `content/` 裡的 markdown 檔案，跑 `./build.sh` 重新產生 HTML。

推上 `main` 後 GitHub Actions 會自動建置並部署到 GitHub Pages。

本地建置需要 [pandoc](https://pandoc.org/installing.html)。
